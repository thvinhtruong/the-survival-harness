# Research

Cited digests of external sources — vendor docs, library references, specs,
standards — written by the `researcher` agent while a goal or a debug log needed
them. Link a digest from a goal state's evidence or a debug lesson rather than
re-pasting the material.

One file per topic, `YYMMDD-<topic-kebab>.md`. Extend an existing digest rather
than starting a second one on the same topic. Every claim carries its source URL
and, where the source states one, the version or date it applies to.

A write destination, not context to load: read a digest only when the task
touches its topic.
